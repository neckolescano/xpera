# xpera CRM — project notes

IT13L (3462) individual project by Nicho Lescano (BSIT 3rd year), instructor Renz Arriola.

## What it is
xpera is a desktop CRM for small stores that sell gaming PC parts. It helps a store remember every customer: who they are, what they buy, what they owe, and what they need. Name story: **xpera = XP + era** ("the era of experience"). Tagline: **Level up every customer.**

## Tech stack
- C# Windows Forms in Visual Studio Community 2026 (.NET desktop development workload)
- SQL Server (Express or Developer) managed in SSMS 22
- ProjectLibre for the schedule / Gantt chart

## Scope: multi-tenant (from the teacher's lab exam plan, 2026-10-21)
Xpera is the company; xpera CRM is sold as a subscription. Each store = a **tenant** with its **own database**. Plans build on each other:

| Level | Includes | Lab exam |
|---|---|---|
| **Tenant A** (micro store) | Main transactions (customers, sales, payments) + data collection (inquiry, complaints, feedback) | First lab exam |
| **Tenant B** (small store) | A + business intelligence (strategic KPIs, dashboard with **6 graphs**, operational reports → print/PDF) + actions (retention) | Second lab exam |
| **Tenant C** (medium store) | A + B + branching | Final |
| **Master** (Super Admin) | Admin panel, BI across all tenants, subscriptions — own database | Final |

Demo data: **at least 200 transactions**.
