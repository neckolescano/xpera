HOW TO OPEN ONE (once per file)
1. ProjectLibre > File > Open > pick the .xml (set the file type to XML if you don't see it).
2. If the project starts on today's date instead of Oct 30: Project > Information > Start date = 10/30/26 > OK.
3. Right away: File > Save as > ProjectLibre (.pod), same folder, same name. From then on open the .pod.
   (Never press plain Save on an .xml: ProjectLibre renames it with "_tmp0".)
4. Money: right-click a column header > Insert column > Cost. The top row is the project total.

ICONS
- Gear on resources = "This resource is on the project team". Normal.
- Calendar on a task = a date constraint. To clear all: click the gray corner box above row 1,
  Task > Information > Advanced > Constraint type = As soon as possible > OK.

To change hours or rates: edit the numbers in make-schedules.py and run:  python make-schedules.py
The "old" folder has earlier versions. You can delete it.
